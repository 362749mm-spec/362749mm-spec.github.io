# 指数复利实验室 · 网页版

静态网页，直接打开就能用：<https://362749mm-spec.github.io/>

收录全球主要宽基指数的真实历史月末数据，做定投模拟、历史回测、指数比较、通胀换算、回撤与退休提取测试。全部计算在浏览器本地完成，不需要登录。

- `index.html`：构建好的完整页面（数据已内嵌）
- `vendor/echarts.min.js`：ECharts 5.5.1（Apache-2.0），图表组件

源码（含数据构建脚本）在私有仓库 `362749mm-spec/xiao` 的 `compound-lab/` 目录，这里只是把它原样发布成网页，代码未做改动。

所有结果都是历史回测或数学推算，不代表未来收益，也不构成投资建议。
